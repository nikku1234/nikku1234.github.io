# Nikhil Ramesh — Robotics & Systems Engineer

Personal portfolio for Nikhil Ramesh, SDE II in Performance Platform Engineering at Amazon Robotics.

The site presents work across fleet-scale robotics simulation, distributed AWS infrastructure, CI/CD, developer interfaces, technical leadership, and agentic triage systems.

## Stack

- React 19 and React Router
- Vite
- Custom responsive design system
- GitHub Actions and GitHub Pages

## Development

```bash
npm ci
npm run dev
```

## Production

```bash
npm run build
```

Pushes to `master` deploy the compiled `dist` artifact through GitHub Actions.
